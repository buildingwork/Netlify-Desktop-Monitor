# Netlify Desktop Monitor

A lightweight Windows desktop application for checking
website availability and Netlify deployment status.

Features
Check whether a website is responding.

Check Netlify deployment status.

Simple Windows desktop interface.

Manual refresh.

Optional automatic refresh.

Automatic refresh disabled by default.

Configurable website and Netlify badge.

No background service.

No telemetry or user tracking.

PowerShell source and standalone EXE build.

Requirements
Windows 10 or Windows 11.

Windows PowerShell 5.1 or later.

Internet connection.

.NET Framework / Windows Forms available on Windows.

Quick Start - PowerShell
Download or clone this repository.

Edit config.json with your website details.

Double-click launch.bat.

Press REFRESH NOW to check your website.
